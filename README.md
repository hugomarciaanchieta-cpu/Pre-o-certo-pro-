# Preço Certo PRO — versão 6

Protótipo local em HTML, CSS e JavaScript.

## Novidade da versão 6
- Orçamento pode mostrar os itens incluídos no preço: mão de obra, materiais fornecidos pelo profissional, deslocamento, alimentação e outros custos informados.
- Os materiais só aparecem como item quando o profissional informou que ele mesmo fornecerá os materiais.
- O documento não revela o lucro estimado do profissional.
- O histórico do orçamento passa a registrar o custo e a diferença estimada quando houver cálculo anterior.

## Como testar
Abra `index.html` em um navegador moderno. Os dados são armazenados localmente no navegador; não existe login real, banco de dados online nem integração ativa com a Monetizze nesta versão.

## Limitação importante
Os percentuais de adicional são parâmetros definidos pelo usuário e não constituem pesquisa de mercado nem garantia de preço aceito. Antes de comercializar o produto, ainda será necessário implementar e testar autenticação, armazenamento online, segurança, painel administrativo, pagamentos e publicação.
